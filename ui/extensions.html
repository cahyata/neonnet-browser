ABOUT EXTENSIONS IN NEONNET BROWSE GREASY FORK ↗
  • Chrome Web Store (.crx) extensions are not used: Chrome extensions depend on Chrome's own toolbar buttons, popup windows, and chrome.* browser APIs. NeonNet uses its own custom Win32/synthwave UI (with Chromium extensions switched off) so third-party Chrome windows never pop up outside NeonNet.
  • Userscripts (.user.js) run natively: You can install standard .user.js scripts (the same format used by Tampermonkey & Violentmonkey) from sites like Greasy Fork or write your own to customize websites, hide clutter, add page buttons, or inject custom CSS/JS.
  • Supported headers & APIs: @name, @version, @description, @match, @include, @exclude, @run-at (document-start, document-end, document-idle), plus GM_addStyle, GM_getValue, GM_setValue, GM_deleteValue, GM_listValues, GM_openInTab, GM_info, and GM.* equivalents.
  • Already built into NeonNet: Ad & tracker blocking (~82,000 domains) and smooth scrolling are built directly into Settings without needing an extension.
Saved locally in %LOCALAPPDATA%\NeonNet\userscripts\ Shortcut: Ctrl+Shift+E or neonnet://extensions
INCOGNITO MODE — Existing enabled userscripts run on websites, but adding, editing, toggling, or deleting scripts is disabled in incognito windows.
Tip: You can also drag and drop a .user.js file onto this page, or paste code into + NEW SCRIPT. Reload open tabs after enabling or editing a script.
