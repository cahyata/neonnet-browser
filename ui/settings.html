PRIVACY 03 // DATA

Clear browsing data Deletes the data you tick, for the chosen period. Cookies and site data also sign you out of sites. The cache is always cleared completely. Single history entries can be removed on the history page.

EXTENSIONS (USERSCRIPTS) 05 // SCRIPTS & SECURITY

Userscripts (.user.js)
MANAGE

SECURITY

HTTPS-only modeOpens every http:// address over https:// instead. If the site has no secure version, NeonNet asks before using plain http. Addresses on this computer or the local network are left alone.
Block trackers and ads
DNS-over-HTTPS (DoH)Encrypts domain name lookups over HTTPS instead of sending plain DNS queries to your ISP or local network.
DoH providerUsed when DNS-over-HTTPS is set to Secure.
Custom DoH template URLMust start with https:// (for example, https://dns.example.com/dns-query).

PROXY TUNNEL

Built-in Proxy TunnelRoutes only NeonNet browser traffic through your selected SOCKS5 or HTTPS proxy server (other Windows apps stay on your normal network). NeonNet tests TCP reachability before enabling so a dead proxy won't cut your internet.
Prevent WebRTC IP leaksSets Chromium WebRTC IP handling to disable non-proxied UDP while the proxy tunnel is active.
Proxy server profilesAdd an external SOCKS5/HTTPS proxy server or a local tunnel (SSH -D 1080, Tor 9050, Clash/V2Ray). Saved passwords are encrypted with Windows DPAPI.
ADD PROXY PROFILE

SCROLLING 06 // INPUT & DEVTOOLS

Smooth scrollingMouse wheel and keyboard (arrows, space, page up and down, home, end) scroll with an easing animation, as the Smooth Scroll extension does. A touchpad is left alone, it is smooth already.
Scroll distanceHow far one step of the mouse wheel moves the page.
SmoothnessHow long the scrolling animation takes.

DEVELOPER TOOLS

Position of the developer tools (F12)Docked in the NeonNet window below, right or left of the page, or in a window of their own. Applies the next time they open.

LOOK

Bookmarks barShows your bookmarks and folders in a bar under the address bar (Ctrl+Shift+B).
Network speed in the status barShows download (cyan) and upload (pink) speed at the bottom left. It is the speed of the whole computer over Ethernet, Wi-Fi and mobile data together, not of NeonNet alone.
Force dark modeAutomatically turns light websites dark using Chromium's built-in Auto Dark Mode while keeping images and NeonNet pages unchanged.
ScanlinesA thin CRT line effect over every page. Purely visual.
