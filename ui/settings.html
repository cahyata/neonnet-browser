PRIVACY 03 // DATA

Clear browsing data Deletes the data you tick, for the chosen period. Cookies and site data also sign you out of sites. The cache is always cleared completely. Single history entries can be removed on the history page.

SCROLLING 06 // INPUT & DEVTOOLS

Smooth scrollingMouse wheel and keyboard (arrows, space, page up and down, home, end) scroll with an easing animation, as the Smooth Scroll extension does. A touchpad is left alone, it is smooth already.
Scroll distanceHow far one step of the mouse wheel moves the page.
SmoothnessHow long the scrolling animation takes.
