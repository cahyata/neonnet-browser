SITE PERMISSIONS

> WHAT EACH SITE MAY USE: CAMERA, MICROPHONE, LOCATION AND MORE

When a site asks to use your camera, location or another feature, NeonNet asks you once and remembers the answer for that site. Sites listed here have an answer. ALLOW lets the site use it, BLOCK refuses it, ASK removes the answer so you are asked again. You can also change them for the page you are on with the lock icon in the address bar. A change reaches a page that is already open when you reload it. Incognito windows keep answers in memory only.
