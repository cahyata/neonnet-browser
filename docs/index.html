NeonNet Browser User Guide

Fast, lightweight Windows desktop browser powered by Chromium Embedded Framework (CEF) with built-in ad blocking, userscripts, performance controls, and a retro neon shell.

Getting Started

  • Address bar: Type any URL or search term and press Enter. Focus it anytime with Ctrl+L or F6.
  • Tabs: Open with Ctrl+T, close with Ctrl+W, and reopen the last closed tab with Ctrl+Shift+T.
  • Menu: Click the ≡ button on the top-right to access bookmarks, history, downloads, extensions, performance panel, scanlines, settings, updates, and this guide (F1).
  • Incognito: Press Ctrl+Shift+N for a separate session whose history, cache, and cookies are wiped on exit.

Extensions (Userscripts)

NeonNet supports userscripts (.user.js) via neonnet://extensions (Ctrl+Shift+E).

Why not Chrome Web Store (.crx) extensions?
NeonNet uses a custom Win32/HTML Alloy shell instead of the full Chrome browser toolbar UI, so Chrome Web Store extension popups and APIs are not loaded. Standard .user.js userscripts (compatible with Tampermonkey/Violentmonkey metadata) run cleanly on matching pages instead.
  • Supports @name, @version, @description, @match, @include, @exclude, and @run-at (document-start, document-end, document-idle).
  • Provides GM_getValue, GM_setValue, GM_deleteValue, GM_listValues, GM_addStyle, and GM_info.
  • Scripts are stored as plain files in %LOCALAPPDATA%\NeonNet\UserData\userscripts\.

Performance Panel & Network Limiter

Press Ctrl+Shift+M or open ≡ → Performance panel to monitor and control NeonNet resources in real time:

  • RAM & CPU meters: Live total memory and CPU usage across NeonNet processes, plus Trim memory to release unused working set pages.
  • CPU / RAM limiters: Optional caps to keep background tabs light on battery or low-spec machines.
  • Network limiter: Set download/upload bandwidth caps (KB/s or MB/s) for testing or conserving connection bandwidth.
  • Tab sleep: Automatically suspends inactive background tabs after an idle timeout.

Privacy & Data

  • Ad & Tracker Blocker: Toggle in ≡ or neonnet://settings to block common ad/analytics hosts before requests leave your machine.
  • Local Storage: Bookmarks, history, settings, and userscripts stay local on your PC under %LOCALAPPDATA%\NeonNet\.
  • Incognito Mode: Uses an isolated temporary profile directory that is automatically deleted after the Incognito window closes.

Crash Logs & Updates

  • Auto-Update: Installed copies check GitHub Releases once a day (or manually via ≡ → Check for updates) and verify SHA-256 checksums before applying.
  • Crash Logs: Unexpected crashes write a diagnostic log to %LOCALAPPDATA%\NeonNet\UserData\crash.log (including exception code, address, and stack trace) for easier bug reporting.
