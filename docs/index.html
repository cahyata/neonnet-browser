01 // GETTING STARTED NAVIGATION & SHELL

Address Bar & Suggestions Press Ctrl+L or F6. Type a URL or search query; local matches rank bookmarks and history offline before anything leaves your PC.
Tabs, Pins & Reopen Drag tabs to reorder, middle-click or press Ctrl+W to close, right-click to pin, and restore closed tabs with Ctrl+Shift+T.
Audio Indicator & Mute Tabs playing audio pulse a speaker icon in the tab strip. Click it to mute/unmute, even across tab sleep cycles.
CRT Scanlines Click SCAN next to the address bar or toggle it in ≡ → Scanlines for the retro monitor overlay.

04 // EXTENSIONS (USERSCRIPTS) CTRL+SHIFT+E

NeonNet runs userscripts (.user.js) from neonnet://extensions so you can customize websites without bloat.

WHY USERSCRIPTS INSTEAD OF CHROME WEB STORE (.CRX)?
NeonNet uses a custom Win32 + HTML Alloy shell instead of the full Chrome browser toolbar UI, so Chrome Web Store .crx extension popups and Chrome-runtime extension APIs are unavailable. Standard Tampermonkey / Violentmonkey-style .user.js scripts run cleanly on matching pages instead.
  • Metadata headers: Supports @name, @version, @description, @match, @include, @exclude, and @run-at (document-start, document-end, document-idle).
  • GM APIs included: GM_getValue, GM_setValue, GM_deleteValue, GM_listValues, GM_addStyle, and GM_info.
  • Easy import: Drag and drop any .user.js file onto neonnet://extensions, click + NEW SCRIPT, or edit files in %LOCALAPPDATA%\NeonNet\UserData\userscripts\.

05 // PERFORMANCE & NETWORK LIMITER CTRL+SHIFT+M

Click PERF on the toolbar or press Ctrl+Shift+M to open the live resource panel:

  • Live Telemetry: Real-time RAM & CPU breakdown across tabs, browser shell, and Chromium helper processes. Tabs above 20% CPU are tagged HOT.
  • Clean Memory: Triggers garbage collection and trims unused Windows working-set pages immediately.
  • RAM Limiter & Tab Sleep: Set a total memory cap (1–8 GB) or put idle background tabs to sleep while protecting tabs marked SOUND, TYPING, or AWAKE.
  • CPU Limiter: Applies low priority and Windows Efficiency Mode to background tabs so your active tab stays responsive.
  • Network Limiter: Throttle download bandwidth (Off, KB/s, or MB/s) for All tabs or Background tabs only.

06 // PRIVACY, GHOST MODE & AD BLOCKER LOCAL FIRST

> GHOST MODE (INCOGNITO • CTRL+SHIFT+N)
Opens a green-accented window backed by a temporary profile folder. History, cookies, and site storage from that session are deleted automatically after the window closes. Bookmarks and downloaded files remain saved.
  • Ad & Tracker Blocker: Built-in domain blocker (toggle in ≡ or neonnet://settings) stops known ad and tracking requests before they connect.
  • Local Data Directory: Bookmarks, history, settings, and userscripts live locally under %LOCALAPPDATA%\NeonNet\. Clear browsing data anytime in neonnet://settings.

07 // AUTO-UPDATE & CRASH LOGS MAINTENANCE

DIAGNOSTIC CRASH LOGS
If NeonNet exits unexpectedly, it writes a stack trace, exception code, and timestamp to %LOCALAPPDATA%\NeonNet\UserData\crash.log (without needing a debugger or extra runtime DLLs). Attach this file when opening an issue on GitHub.
  • Verified Updates: Installed builds check GitHub Releases at most once per day (or manually via ≡ → Check for updates) and verify the installer SHA-256 checksum before applying.
