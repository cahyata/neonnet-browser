Color

Colours are named for their role. The values below are read live from ui/tokens.css, so they follow the theme buttons above. Change a value in design/tokens.json, run tools/gen_tokens.ps1, and reload.

Two system fonts, no font files. Mono for everything; the display face only for page heroes. The smallest text is 11px.

NeonNet has no rounded corners. Corners are cut with clip-path using the --cut-* tokens.

Actions

Primary actions are pink-outlined, toggles show their state as a word, delete and clear are red and ask for a second click. Focus is drawn inside the clipped GO button: press Tab to see it.
